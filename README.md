# 홍홍 사이언스 홍승현 강사 홈페이지

14년 현장 경험으로 차별화된 AI 강사, 홍홍 사이언스 홍승현을 소개하는 한 페이지짜리 홈페이지입니다.

## 파일 구조
- `index.html` : 페이지 내용
- `css/style.css` : 색과 배치 (검정·남색 바탕 + 금색 포인트)
- `js/main.js` : 메뉴, 스크롤 효과, 숫자 올라가기, 이메일 조합
- `js/boot.js` : 자바스크립트가 켜져 있음을 CSS에 알림
- `images/` : 사진 (profile.jpg, banner.webp, logo.webp, og.jpg)
- `netlify.toml` : Netlify 배포 설정과 보안 헤더

## 내 컴퓨터에서 보기
`index.html` 파일을 더블클릭하면 브라우저에서 열립니다. (샘플 영상은 인터넷에 배포된 주소에서만 재생됩니다.)
